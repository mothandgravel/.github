The conditions have a source.
Weather, wave and sea-level observations. The full download contains 100 series and 2,400 requested sample slots. Missing values keep their original NaN text alongside an empty numeric value.
All selected channels have verified parameter units. A blank unit in the full export means the retrieved metadata did not supply one.

AIS / NO DAY TRACK RECOVERED
We asked for a day.
A commercial MyStar control returned zero fixes for the requested 11 November window and one latest control fix dated 13 November. That latest-fix endpoint did not recover an archived track.
It establishes no vessel absence. The original failed HTTP 406 request was corrected with the required gzip header; a failed request was not counted as empty data.

PUBLIC ARCHIVES / SNAPSHOT OF AVAILABILITY
The date has not arrived everywhere.
The Danish public AIS listing retrieved on 13 November contains daily files through 10 November. No 11 November file was listed. Danish shore-based coverage does not establish Gulf of Finland coverage.
The retrieved Helsinki daily seismic calendar also stops at 10 November. A publication gap is not a measurement of silence. No waveform has been analysed or attributed.
