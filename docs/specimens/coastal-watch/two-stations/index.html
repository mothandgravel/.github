What this run changes

Starts with empty queues and clear journey conditions. Captures live AIS at South with low priority, interrupts its link, and records a failed connection check. After you continue, up to three captures look for a strictly newer source report from the same vessel. Those reports enter the queue with high priority.

You release the burst. Newer reports pass first; one accepted request returns 503 to exercise a retry. The older report follows. Success requires receiver evidence that a newer position was retained. The crossing below can replay the recorded journey at reading speed.

Stop restores the link after the current request finishes. Captured reports and receipts remain. Closing or reloading this page ends the guide but leaves the service conditions and queue intact; inspect them before sending. This tab coordinates the run: avoid changing the same service from another tab.

Source, method & limits Read the small print +

Manual capture from Fintraffic / Digitraffic, CC BY 4.0. Filtered to this Helsinki-area view and source reports from the last ten minutes; at most ten new reports per capture, newest first. Minimum 15 seconds between captures. Coordinates are unchanged. No background feed runs. The same public source at two illustrative stations is not independent corroboration. Coastline: Natural Earth, public domain, 1:10 million source scale.

To inspect a late arrival: queue a low-priority report, wait, queue a newer high-priority report, then send. Queue priority determines delivery order; source time determines the latest report.

Interrupting the link returns HTTP 503 to the connection check. Refusing delivery returns 503 without accepting a report. Losing one acknowledgement commits acceptance, then returns 503 once. This models response failure; it does not prove packet loss. A queue’s failed-batch count increases after a burst exhausts its retries, not per HTTP attempt. Unfinished attempts have unknown outcomes; receiver records may still show acceptance.

Unsigned local rehearsal. Both stations use this host’s clock. Public AIS is not a complete traffic picture. This is not an authenticated operational network or a navigation aid. Reloading preserves queues and receipt history.

What changed the design

A useful doubt.
Kept in the record.

Two clocks look like a small detail. They change the story we can honestly tell.

Read The picture stays. ↗

At seven minutes, the stations disagree. Both are faithfully showing the reports they have received. Looking back with later arrivals gives us a fuller account of those minutes. It does not give the earlier operator that knowledge.

This study carries forward Raivari’s recorded-clock replay, explicit outage experiments, station-availability comparison. It adds a separate receipt clock: a newly delivered report may describe an old position. The interaction and receipt model here are new. Its positions and transport delays are authored so the same question can be repeated.

The research, and the design choices it supports
  1. NATO, Data Quality Framework for the Alliance (2025), paragraphs 12 and 18–23. We expose age, source, transformation path and duplicate receipts separately. The framework informs the questions; this study makes no claim of conformance or endorsement.
  2. García-Fernández and Yi, Continuous-discrete multiple target tracking with out-of-sequence measurements (2021). A delayed measurement belongs to an earlier state. Our historical view makes that distinction visible; it does not implement the paper’s Bayesian tracker.
  3. Gaglione and colleagues, Fusion of Sensor Measurements and Target-Provided Information in Multitarget Tracking (2021). This CMRE, US and Austrian collaboration distinguishes sensing from cooperative reporting and models asynchronous observations. We keep radar and AIS origins visible; fixture identity is assigned, with no inferred association.
  4. Dagdilelis and colleagues, Cyber-resilience for marine navigation by information fusion and change detection (2022). The study evaluates multiple sources using sea-test data and simulated spoofing. It motivates a separate baseline and altered run here. Our animation demonstrates no spoofing-detection performance.
  5. NATO CMRE, Sea Signals: Baltic data at CWIX25. Maritime data exchange and interoperability provide the Baltic context. These fictional stations do not represent that exercise or a deployed network.
  6. DLR, HAXR multi-station radar dataset, v1.1.0. Raivari’s existing investigation separates acquisition-window differences from proven clock error and treats shared AIS reports as one source. We retain those distinctions. No HAXR recording is transplanted onto this Finnish coastline.
What comes from Raivari

The existing replay keeps source recordings intact while an experiment changes their availability. Its station comparison keeps shared AIS lineage visible. Its tracker view excludes future snapshots. Those are the foundations of this study.

Raivari also has a durable offline queue, burst delivery with acknowledgements and retries, and audit signing. The authored replay does not run those services. The local transport mode now connects the actual queue and burst-sync service to a persistent receiver ledger. Audit signing is not connected. Together they expose which original report reached which station, and when. The server records every actual HTTP attempt, accepted or rejected receipt, and duplicate without replacing the original observation.

We reviewed these paths and ran sixteen existing replay tests. This was a focused review, not an exhaustive audit of Raivari. The source record maps each existing piece to this specimen, its limits and the remaining integration.

Read the limits of this experiment

One fictional contact; sixteen authored observations; local and relay receipts; one explicitly configured interruption. There is no radar signal processing, sensor fusion, prediction, identity inference, sensor-health diagnosis or threat assessment. A transport interruption does not establish a sensor failure.

Positions use WGS84 longitude and latitude in a local equirectangular plot. Source timestamps are assumed consistent for this experiment. Uncertain clocks, packet loss, multiple targets and conflicting identity claims need separate experiments. The 120-second default age limit is a demonstration choice, not a maritime operating limit.

“Look back” admits only observations made by the cursor and received by the scenario’s end. It is bounded hindsight, not ground truth. Observation history remains unchanged when returning to “As known then”. No operator-comprehension study or operational validation has been performed.
