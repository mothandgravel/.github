ORIGINAL OPERATION—
    Use Ajo and Raivari RPC on your machine

    The public view replays captured executions. A local host can create new, isolated file-change runs. It listens on loopback, uses the pinned source files, and exposes no arbitrary command or file selector.

    Prepare the runtime using the local setup guide, then open http://127.0.0.1:8796/specimens/maintenance-acceptance/?mode=live. Every dispatch changes only its run’s document.txt. The injected interruption exits Ajo’s evaluator after receiver commit.

    Runtime failure remains a failure. The workbench does not substitute an authored response when Ajo is unavailable.

    A REAL MAINTENANCE FAILURE

    The change landed.
    The station still waits.

    A relay is taken out of service for maintenance. Bringing it back involves two different things: applying the agreed configuration and demonstrating that its consumer can use it again. A lost acknowledgement makes it tempting to repeat the change. A successful write makes it tempting to close the job.

    Here a separate Python HTTP process reloads the real configuration file. Ajo applies the change, then deliberately exits before retaining its reply. Recovery queries the original operation. A separate client subsequently requests /station-status and checks the HTTP status and configuration digest reported by the running relay.

    The second account leaves maintenance mode enabled in the approved configuration. Its receipt is successful, but the real station request receives HTTP 503. Acceptance stays held. This exercises a realistic handback failure; it is not evidence from a deployed support site.

    WHAT TRAVELLED WITH US

    Small tools.
    Explicit limits.

    Ajo supplies the unchanged native evaluator, filesystem receiver, effect checks and recovery semantics. Raivari RPC supplies the unchanged input fingerprint and execution guard. This site supplies the local adapter, operator approval record, acceptance rule and interface.

    The RPC guard’s allowed decision is a preflight result, not a signature or an atomic authority lease. The receiver receipt establishes this bounded file operation. Neither establishes equipment safety, calibrated timing or acceptance by another organisation.

    Recorded steps retain their original evidence; replay sends nothing. Local runs survive page reload in the running laboratory environment. Export what you need to retain.
