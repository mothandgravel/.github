# 21 November 2026 / evening source recheck

This packet supplements the original 21 November Coastal watch snapshot. Helsinki and Tallinn used EET (UTC+02:00) on this date.

- **EUMETSAT GeoColour:** seven exact WMS requests from the initial snapshot were repeated successfully. The 1100 × 400 PNG responses were decoded and verified as distinct. The shared regional bounds are 23–28.5° E and 59–61° N. The WMTS provider time list returned 127 ten-minute labels between 00:00 and 21:00 EET. The saved images are the seven labels from 09:00 to 10:00 EET. Product labels, receipt timestamps and pixel acquisition are separate. Exact pixel acquisition and first publication are unknown. EUMETSAT imagery is [CC BY 4.0](https://user.eumetsat.int/catalogue/EO:EUM:DAT:0913). The [GeoColour layer](https://view.eumetsat.int/productviewer/productDetails/mtg_fd:rgb_geocolour?v=default) uses NASA Black Marble for its static night background.
- **NASA GIBS:** two unmodified MODIS Corrected Reflectance True Color WMS crops, from Terra and Aqua respectively, with the same bounds. The product date is 21 November. Exact acquisition times within that day are unknown. Imagery from [NASA Earthdata GIBS](https://www.earthdata.nasa.gov/data/tools/gibs).
- **Copernicus:** the original Sentinel-1 and Sentinel-2 catalogue requests returned structurally identical JSON on recheck, with seven and 17 entries respectively. The response bytes and their separate retrieval receipts are retained. This packet contains no Sentinel image pixels.
- **Estonian Environment Agency:** the same three-station hourly archive filter produced an empty array for each of the original window, the elapsed day through 21:00 EET, and the whole local day. The 11 November control returned 144 rows. The bounded latest-label probe is a lag diagnostic for the groups returned. The [agency documents daily publication](https://keskkonnaportaal.ee/et/avaandmed/hudroloogilise-seire-andmestik/hudroloogilise-seire-andmestiku-kirjeldus). The agency's separately maintained operational coastline table supplied 12 station rows at 09:00, 12:00, 17:00 and 21:00 EET. Each record preserves the displayed UTC label and decimal strings for sea level in cm EH2000 and water temperature in °C. Values are operational and unchecked. Exact sensor times, averaging and first publication are unknown. They are distributed as exact field extracts under the [agency's CC BY 4.0 dataset terms](https://keskkonnaportaal.ee/et/avaandmed/hudroloogilise-seire-andmestik). Table response receipts identify the four source pages and bind the original HTML retained in the research capture.
- **AIS:** the bounded Fintraffic morning query returned the original position response byte for byte. The separately bounded 10:00–13:00 EET query returned no locations. The Danish date-prefix query remained empty and the complete November prefix ended at 18 November. The responses describe these queries at capture time. No Danish 21 November archive was available to test for coverage.

Every published response or extract is listed in `sha256.json`. Receipts retain the requested URL, UTC retrieval clocks and original response hashes where available.
