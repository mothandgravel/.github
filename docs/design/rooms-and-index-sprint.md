# Light through the rooms / studio index

This pass gives Moth & Gravel's existing materials a clearer spatial relationship. Bone paper, charcoal, brass, condensed type and the italic serif stay the vocabulary. The questions and actual specimen records remain the subject.

## Five decisions

- **Light:** a stronger, soft key from above-left reveals the studio mark against its darker mount. The engraved frame, label and down/right contact shadows share that direction. A small inline SVG grain lives in backgrounds, without filtering text or fetching an image.
- **Planes:** the specimen mount, actual image, caption and working record read as separate surfaces. The original outputs and full-size routes remain available. Inner shell wrappers allow the rooms to fill the viewport while retaining their readable width and offscreen rendering containment.
- **Responses:** fine-pointer image enlargement is 1.2%, inside the mount's padding. The index marker responds to hover and keyboard focus. Headlines, captions, summaries and link geometry remain still. Keyboard use, coarse pointers and reduced motion retain a still image.
- **Atmosphere:** Field Notes occupies pale paper; working specimens occupy a dark material room in both surrounding themes. These are local material contexts, like the existing dark moth stage. Article themes still follow the reader's preference.
- **Navigation:** the existing authored links become a numbered studio index with supporting hints and an enquiry invitation. The sheet uses the studio's own typography and copy. Wide screens retain shortcuts; compact screens use Menu. No new client portal or submission flow is introduced.

## Handling and recovery

The sheet is a nonmodal disclosure. Opening focuses the first route. Escape restores its trigger; tabbing out, outside pointer interaction and leaving the page close it. Same-page room selection moves focus to its destination. Width changes close safely; height changes resize the sheet naturally, including mobile browser chrome. Its finite arrival is suppressed for reduced motion. There is no scroll hijack, continuous scene or pointer-following light.

The index is built from each masthead's own links, preserving nested-page destinations. Its enquiry link resolves from the existing home link. Readiness classes appear only after the controls are installed: missing JavaScript leaves visible ordinary navigation and hides dead buttons. The generated homepage stylesheet explicitly retains the dynamic classes. Shared brand links use their actual visible text as the accessible name.

## Review

The dedicated browser review covers eight widths, both themes, open/closed focus, outside and keyboard exit, responsive bounds, nested routes, reduced motion, touch, script failure and no JavaScript. It compares the reading/control rectangles through material handling and checks small image response separately. Navigation accessibility is checked on the visible index; room accessibility is checked after rendering the rooms. Existing full landing, enquiry, moth, handling, actual-render and cold-load gates remain required.

Screenshots and measurements are development/workflow artifacts. The site gains no bitmap asset, font, animation library or external rendering dependency. These browser checks establish exercised behaviour; they do not measure comprehension or motion comfort with people.
