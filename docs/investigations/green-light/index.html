CYBER GRID / A ROUTE CHECK, REDUCED

Can this board be finished?

Cyber Grid checks every daily board for a route before anyone plays it. Here is that check on a smaller board. Place obstacles, then ask. Shrink the search budget and watch “not found” stop meaning “no”.

Then follow the four pieces of work below.

This toy needs JavaScript. In words: the search either finds a route you can check, proves there is none, or runs out of steps. Running out is not a no.

A 5 × 5 reduction using the game’s jump rule and route search, restyled. The game itself plays on a larger board.

01 / GEAIDNU

Geaidnu
Prototype

Running is
not finished.

Geaidnu is a calm cockpit for work in progress: the current task, the repositories and services behind it, and the evidence. It keeps two answers apart. A healthy runtime is an observation about the runtime. Accepted work needs evidence of its own.

When a probe fails, the answer stays unknown. A check that could not see the service cannot say it stopped.

02 / FLUTTER-TEST-RS

flutter-test-rs
Prototype

Green,
on which machine?

A Flutter test runner that minds the machine it runs on.

The question it keeps asking: when a run comes back green, what did it actually run, and where? A pass from a machine that skipped part of the suite should not look like a pass from one that ran all of it.

03 / DECISION DOCKET

Decision Docket
In production for our own work

Merged is
not verified.

Our own tool for the decisions and evidence behind software work, in production for our own work. It records a merge as a merge. Whether the change was verified is a separate claim, and it needs captured evidence of its own.

A green check beside a merge is easy to read as both. The workspace keeps them on separate lines.

Shown here only through fictional examples. The real workspace holds private work.

04 / CYBER GRID

Cyber Grid
Playable, link coming

A route,
or no answer yet.

A daily logic puzzle: visit every node once, in jumps. Before a day’s board is served, a search looks for a route through all of it. A board without one found is rolled again.

The search is bounded by a count of steps, not a clock, so every device reaches the same verdict. Running out of steps counts as “not guaranteed”, never as “impossible”. The board at the top of this page keeps those two apart, so you can see the difference.

The same check found two daily rules that could never be finished on their board: one allowing only straight jumps, one only diagonal. They were replaced.
