# Evidence: studio design sprint (2026-10-17)

- `studio-sprint/current/` contains screenshots of the current Tk studio. They come from the repository's own UI fixtures (`STUDIO_SCREENSHOT_DIR`) under Xvfb, plus a few extra fixture-driven states captured with the same harness. All media, jobs, failures and publication states are controlled examples. No Cloud requests were made.
- `studio-sprint/prototypes/` contains static Tk mock windows rendered by `design/studio-sprint/mockups.py`. They are illustrations only: every price, time and provider state is invented.
- `studio-sprint/compare/` pairs each current state (left) with its prototype (right).
